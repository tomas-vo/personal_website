## English

Personal portfolio site for Tomás Venegas Osses — software development student, entrepreneur, and automation builder. Built with plain HTML, CSS, and JavaScript, with no frameworks and no build step.

**🔗 Live site:** [tomas-vo.github.io/personal_website](https://tomas-vo.github.io/personal_website/)

### Features

- Full site available in 4 languages: Spanish, English, Portuguese, and French
- Interactive hero animation that draws the real Collatz trajectory for n = 27 on a `<canvas>`
- Full thesis writeup on computational analysis of the Collatz conjecture, with a Random Forest predictive model
- Verifiable certifications and credentials page (badges, language certificates)
- Minimalist dark design with subtle, purposeful animations
- Zero build dependencies — just open the HTML files in a browser

### Project structure

```
personal_website/
├── index.html              # Main portfolio page
├── tesis.html               # Full thesis writeup
├── certificados.html        # Certifications & credentials page
├── styles/
│   └── style.css            # Shared styles for all 3 pages
├── scripts/
│   ├── script.js            # i18n, animations, index.html logic
│   ├── tesis.js              # i18n & logic for tesis.html
│   └── certificados.js       # i18n & logic for certificados.html
└── images/                  # Photos, org logos, thesis figures, credentials
```

### Tech stack

| Technology | Use |
|---|---|
| HTML5 | Semantic markup |
| CSS3 | Custom properties, Flexbox, Grid, animations |
| JavaScript (vanilla) | i18n system, DOM interactions, Canvas API |
| Canvas API | Live-drawn Collatz trajectory animation |
| Google Fonts | Space Grotesk (display), Inter (body) |
| highlight.js (CDN) | Code syntax highlighting in `tesis.html` |

### Run locally

No installation needed — this is a static site.

```bash
git clone https://github.com/tomas-vo/personal_website.git
cd personal_website
```

Then just open `index.html` in your browser.
